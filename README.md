# JavaScript-First Static Template (Blueprint v2)

GitHub Pages URL:
https://<owner>.github.io/<repo>/

This repository is a deterministic, no-Node static web template.

## Local run

1. Build the site:
   ```bash
   ./scripts/build.sh
   ```
2. Start a local preview server:
   ```bash
   ./scripts/dev.sh
   ```
3. Open <http://localhost:8000>.

## Testing

Run:

```bash
./scripts/test.sh
```

The test script performs shell syntax checks and a build smoke test.

## Deployment behavior

- GitHub Pages deploys from a workflow artifact generated from `/dist`.
- Only the latest `main` run deploys (concurrency cancellation enabled).
- `dist/` is never committed and is always reproduced from source.

## CI + artifact deployment

- `ci.yml` runs integrity checks and reusable build workflow.
- `web-build-reusable.yml` builds and uploads the Pages artifact.
- `pages.yml` handles deployment-only orchestration.

## Dist output directory

`/dist` is generated by `./scripts/build.sh` and intentionally gitignored.
